# AGENTS.md — Severance: Lumon Office

(removed from this folder; its leftovers are in `concept/old_cordova/`, see `decisions.md`). Made with the
`game-pipeline` skill: everything 3D is generated by Python in Blender, Godot assembles levels from JSON at runtime.

## Pipeline (rebuild order)

```
python tools/make_textures.py                       # numpy-painted floors/walls -> assets/textures
B="/c/Program Files/Blender Foundation/Blender 5.2/blender.exe"
cd blender/scripts
"$B" -b --factory-startup -P build_props.py         # 71 props -> assets/props/*.gltf + props_info.json (~3 min)
"$B" -b --factory-startup -P build_characters.py    # 11 humans + goat, 19 anims, UI portraits (~4 min)
"$B" -b --factory-startup -P build_world.py         # levels from office_plan.py -> assets/levels + map images
cd ../..
python tools/make_audio.py                          # music + sfx -> assets/audio (~20 s)
python tools/make_ui.py                             # icon, splash, digit atlas, blob shadow
```
Flags: `build_props.py -- --only terminal,desk_pod --no-render`, `build_characters.py -- --only mark,goat`,
`build_world.py -- --only severed`. The floor plans (rooms, doors, props, markers, patrol routes) are data in
`blender/scripts/office_plan.py` — edit there, rebuild the world, and the game picks it up.

## Code map

| File | Role |
|---|---|
| `scripts/game.gd` (autoload `Game`) | state, save/load, settings, texts, command-line flags |
| `scripts/texts.gd` | every string, EN + RU, dialogue lines |
| `scripts/quests.gd` | the 18 directives (steps, rewards), interactable labels |
| `scripts/story.gd` | runs directives: NPC placement, talk/use/pickup, rewards, stealth patrols + vision cones, Graner's naps, OTC switches, the MDE party |
| `scripts/main.gd` | camera, light, input (tap/click/WASD/pinch), level loading, transitions, effects, `--autotest`, `--tour` |
| `scripts/level.gd` | builds a level from glTF + layout JSON, cutaway materials, CRT/CCTV screen shaders, AStarGrid2D, doors, interactables |
| `scripts/actor.gd` | characters: animation, path following, sitting, bubbles, selection ring |
| `scripts/sfx.gd` (autoload `Sfx`) | sounds, music, ambience |
| `scripts/ui/*.gd` | `ui_kit`, `hud`, `dialog`, `menus` (title/pause/settings/archive/map), minigames: `mg_mdr` (refinement), `mg_small` (compunction, printer, wellness, goats, keypad), `mg_dance` (rhythm) |
| `shaders/` | `cutaway` (walls melt around the player), `crt_screen`, `cctv`, `cone`, `post` |

## Google Play

Store art: `python tools/play_store.py` → `renders/play/` (icon, en/ru feature graphics, screenshots from the
autotest at 1920x1080). Texts: `store/listing.md`. Privacy policy: https://severance.lol/privacy.html.
Upload from the built-in browser: serve the repo with a local CORS server on 127.0.0.1 and set the page's
`input[type=file]` from a fetched blob (see the Gem Swap / Hot Bag memory). Release flow: Тестирование и выпуск →
Рабочая версия → Создать выпуск → upload AAB → notes → Далее → Сохранить → Обзор публикации → Отправить на проверку.
