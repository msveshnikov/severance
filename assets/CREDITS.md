# Credits

## Code, models, textures, sounds
Everything in this game is generated by code written for it: Blender Python scripts build every model, rig and
animation (`blender/scripts/`), numpy paints the textures (`tools/make_textures.py`), and numpy/scipy synthesize all
music and sound effects (`tools/make_audio.py`). Nothing was downloaded.

## Music
- Office theme, testing floor drone, stealth ostinato, "Defiant Jazz" swing loop — synthesized by `tools/make_audio.py`.
- `title.mp3` — the title track of the original Severance (Lumon Office) web game by the same owner.

## Art
- The six paintings on the walls (`assets/textures/art_*.jpg`) come from the original web game.
